# 流程優化實驗清單（流程優化師維護）

每個改進都是一個「實驗」：有假設、改了什麼、用什麼指標量、基線、目標、驗證結果。
**狀態**：進行中（等下一輪數據）／保留（有數據證明有效）／回退（無效或有副作用，已還原並記錄）／未定（資料不足，不得宣稱有效）。
數據來源只用 `bin/console ledger report`（用量帳本）與 `bin/console usage`；沒有數據就寫「未驗證」。
規則見 `.claude/agents/process-optimizer.md`「每輪覆盤與閉環」。備份在 `runtime/flow-backup-*/`。

基線（2026-11-19，帳本回補）：27 次子代理、3903k tokens；其中自動派工空轉 1867k（48%）；扣掉它的流程重工約 14%（285k／2036k）；停下來等使用者 9 次；超出工具呼叫預算 3 次；卡住 3 次、失敗 3 次。
